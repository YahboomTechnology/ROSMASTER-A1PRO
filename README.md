# Introduction
The ROSMASTER M1 PRO and ROSMASTER A1 PRO combine advanced mobile platforms with robotic arm to create versatile mobile operation solutions, ideal for robotics development, AI research, robotic education, and embodied intelligence applications.
ROSMASTER M1 PRO adopt omnidirectional Mecanum wheel mobile chassis, enabling flexible movement in multiple directions and precise positioning to efficiently accomplish mobile operation tasks.
ROSMASTER A1 PRO integrates an Ackermann steering mobile platform, which not only replicates the steering characteristics of real vehicles but also possesses robotic operational capabilities.
Both platforms support deep integration of mobility, perception, AI, and operation functionalities, providing a comprehensive development environment for exploring ROS2, computer vision, SLAM, navigation, AI interaction, and embodied intelligence.
